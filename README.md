# 📊 Power BI Sales & Profit Dashboard  
### By Lim Ping Har — Data Analyst

This Power BI project showcases business insights for the Adventure Works dataset, focusing on **sales performance**, **revenue trends**, and **product profitability**.

---

## 🔍 Key Insights
- 📈 **Revenue:** $1.83M (3.3% above target)
- 🏆 **Top Product (Orders):** Water Bottle – 30 oz.
- 💰 **Top Product (Profit):** Mountain-200 Black, 46
- 📊 Tracks KPIs: Total Orders, Revenue, and Returns vs. Targets
- 📅 Interactive filters by Date and Region
